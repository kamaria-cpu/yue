📖 使用说明 / 常见问题
  1. 在 HTML 源码开头的 CONFIG 中把 user、repo 改成你自己的 GitHub 用户名和仓库名。
  2. 仓库需开启 GitHub Pages（Settings → Pages → Source 选择 main 分支根目录）。
  3. 生成 Token：GitHub → Settings → Developer settings → Personal access tokens。Classic 勾选 repo；Fine-grained 给该仓库 Contents: Read and write。
  4. 把 Token 填入上方输入框并保存，之后浏览器会自动记住。
  5. 上传的文件会直接提交到仓库根目录，外链格式为 https://用户名.github.io/仓库名/文件名。
  6. 新提交的文件在 GitHub Pages 上生效可能需要几十秒到几分钟（CDN 缓存），稍等再打开链接。
  7. 删除操作会真实提交一次 commit，无法撤销，请谨慎操作。
